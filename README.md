# GURS JGP podatki

Javni izvoz zbirk z [Javni geodetski podatki](https://ipi.eprostor.gov.si/jgp/data)
(Geodetska uprava RS). V tem repozitoriju so **samo ZIP datoteke**.

Vir in licenca: podatki GURS so informacije javnega značaja pod
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.sl). Pri uporabi
navedi vir, vrsto podatka in datum stanja zbirke.

ZIP-i nad 100 MB so v [Git LFS](https://git-lfs.com/). Klon:

```bash
git lfs install
git clone https://github.com/rtcimi/GURS-jgp-data.git
```

Prenos in osvežitev potekata iz zasebnega repoja `GURS-downloader` (SI/EU IP;
GURS zavrne US cloud).
